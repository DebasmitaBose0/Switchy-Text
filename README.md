# Switchy Text Theme Toggle Demo

A simple, colorful, and responsive mini website built in a single HTML file. It demonstrates theme toggling between Light, Dark, and Auto (system) modes, with a modern UI and interactive features.

## Features

- **Theme Toggle:** Switch between Light, Dark, and Auto (system) themes using a single button. Auto mode follows your device's system theme.
- **Colorful UI:** Vibrant gradient backgrounds, glassmorphism effects, and modern fonts.
- **Typewriter Animation:** Animated project purpose appears below the heading.
- **Input Fields:** Includes a text input and a textarea that adapt to the current theme.
- **Character Counter:** Shows the number of characters in the textarea.
- **Copy Button:** Easily copy the textarea content with a single click and get a notification.
- **Responsive Design:** Looks great on desktop and mobile.
- **Local Storage:** Remembers your theme preference.

## How to Use

1. Open `theme-toggle-demo.html` in your web browser.
2. Use the theme toggle button to cycle through Auto, Dark, and Light modes.
3. Type in the input or textarea. The UI adapts to the selected theme.
4. Use the copy button to copy textarea content.

## Customization

- Change the typewriter text in the JavaScript section to update the project description.
- Adjust colors and gradients in the CSS variables for your own style.
